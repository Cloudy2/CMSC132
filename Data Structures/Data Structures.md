A data structure is a way of representing and storing info, or data.
Choice of a data structure can affect:
+ The [[Abstraction|abstraction]] supported
+ Amount of storage required
+ Which operations can be [[Asymptotic Analysis|efficiently performed]]

Some common data structrues include:
+ [[Stack|Stack]]
+ [[Queue|Queue]]
+ Dictionary (Map)
+ Trees
+ Graphs (like a network)
	+ Connection between data is what's important
